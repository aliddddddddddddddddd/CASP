CASP Experiment Runner

This tool runs the CASP controlled evaluation as a Claude.ai artifact, using the Claude.ai subscription instead of an API key. Follow the steps in order and keep the conversation open while the run is in progress. Results are saved automatically, so an interrupted run can be resumed from where it stopped.

1

Connection test

Checks the connection to Claude and which features are available (Structured Outputs, prefill and prompt caching). Takes less than a minute.

    2

    Experiment settings

    The defaults reproduce the reported run (50 items per task, 1 repetition, 30 caching items). More items or repetitions increase statistical power but take more time and usage.
